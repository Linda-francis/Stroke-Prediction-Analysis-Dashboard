# Stroke Prediction Analysis Dashboard

An interactive Tableau dashboard analyzing stroke risk based on patient health and demographic data.

## Overview
This project explores factors associated with stroke occurrence using an interactive Tableau dashboard, helping identify patterns across age, gender, and health indicators.


## Key Metrics
- **Total Patients:** 5,110
- **Stroke Cases:** 249
- **Average BMI:** 28.89
- **Average Glucose Level:** 106.1

## Features
- KPI cards for total patients, stroke cases, average BMI, and average glucose level
- Work Type by Gender heatmap showing stroke case distribution
- Average Glucose Level by Work Type bar chart
- Gender Distribution pie chart
- Stroke Cases by Smoking Status bar chart
- Stroke Status breakdown by smoking status
- Interactive filters for patient demographics

## Factors Analyzed
Age, Gender, Hypertension, Heart Disease, BMI, Average Glucose Level, Smoking Status

## Tools Used
Tableau, Data Cleaning, Calculated Fields, Parameters

## Insights
The dashboard highlights how age, hypertension, heart disease, and glucose levels correlate with higher stroke risk, supporting early identification of high-risk patient groups.
